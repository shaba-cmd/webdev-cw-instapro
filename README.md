# Instapro

MVP социальной сети для обмена фотографиями

## Деплой

https://webdev-cw-instapro-weld.vercel.app/

## Первоначальная оценка

11 часов

## Фактически затраченное время

7 часов 30 минут

## фунциональность которую удалось реализовать

Интеграция верстки списка постов с API

Реализация страницы добавления поста

Реализация страницы с постами отдельного пользователя

Реализация функции лайков

## список дополнительных фич, которые удалось реализовать

Профиль пользователя благодаря которому можно понять 
в каком аккаунте находишся в данный момент 
в который так же можно зайти для просмотра постов, если они есть

Лайки отображаються не просто колличеством, а показывает кто лайкнул первый
и еще перечесляет сколько других пользователей оставило лайк

Безопасность - HTML-теги, введенные в формах, отображаются как текст и не срабатывают.
